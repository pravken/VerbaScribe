# Промпт для локальной сессии: проверка последних доработок на ПК

Скопируйте всё, что ниже линии, в сессию Claude Code на компьютере с Verbaliox. Можно продолжить ту, где проверяли модели и видеокарту: клон и копия базы там уже есть.

---

Ты работаешь на моём Windows-ПК с Verbaliox (RTX 3090). В ветке `claude/sweet-maxwell-uaextf` появились доработки, которые нельзя проверить без настоящего железа, звука и Outlook. Проверь их и запиши отчёт. Отвечай мне по-русски.

## 0. Подготовка

1. В клоне `Verbaliox-bench` (если его нет — склонируй, как в `docs/model-bench-session.md`) выполни `git checkout claude/sweet-maxwell-uaextf && git pull`.
2. `PY` — это `<папка программы>\.venv\Scripts\python.exe`. Работай с копией базы: `VERBALIOX_DATA_DIR=%TEMP%\vs-bench-data` (обнови копию из `%LOCALAPPDATA%\Verbaliox\meetings.db`), `VERBALIOX_MODELS_DIR=<папка программы>\models`.
3. Прогони тесты: `PY -m unittest discover -s tests -t .`. Если удобно, запусти и браузерный прогон: `tests/ui/smoke.mjs`, описание в его заголовке.
4. Попроси меня закрыть Verbaliox на время замеров скорости.

## 1. Разделение участников после GigaAM

Раньше у GigaAM и Parakeet конец слова совпадал с началом следующего. Из-за этого пауз между словами не было, и разделение по голосам не резало длинные фразы. На записи с двумя собеседниками GigaAM дал одного участника, а Whisper — двоих. Теперь конец слова берётся по его последнему токену (`app/asr_onnx.py`, `_set_ends`).

- Спроси меня, какая запись с двумя-тремя собеседниками подходит: на русском, лучше та, где раньше получился один участник. Расшифруй её моделью GigaAM v3 и затем Whisper large-v3, в копии базы или через программу вместе со мной.
- Сравни число участников и число реплик, а на слух проверь несколько мест, где собеседники сменяются.
- Если разделение всё ещё хуже, чем у Whisper, посмотри `app/diarizer.py` (`_split_segments_by_word_pauses`, пороги 0.48 с и 0.22 с) и время слов в сегментах. Предложи исправление, но без моего согласия не коммить.

## 2. Пачки на видеокарте: что быстрее

На видеокарте GigaAM и Parakeet теперь распознают по 32 фразы за раз (раньше по 8), а VAD при желании тоже идёт на видеокарте. Настройки `onnx_gpu_batch` и `onnx_gpu_vad` лежат в таблице `settings` копии базы.

Замерь `PY tools/model_bench.py fleurs --langs ru --n 80 --models gigaam-v3,parakeet-v3` при:
- `onnx_gpu_batch` = 8, 16, 32, 64 и `onnx_gpu_vad` = false;
- лучшем размере пачки и `onnx_gpu_vad` = true.

Если найдётся запись на 30–60 минут, повтори лучшие два варианта на ней (`library --meetings <id> --clip 0`). Таблицу «пачка / VAD / время / ×реального / видеопамять / WER» положи в отчёт. WER не должен меняться от настроек; если меняется, это ошибка. По результату предложи значения по умолчанию.

## 3. Тихий собеседник

Громкость теперь поднимается по участкам по 10 секунд (`app/asr_onnx.py`, `level`): тихий собеседник рядом с громким не должен пропадать.

- Сделай тестовый файл: возьми фразу FLEURS en_us (они тихие) и громкую фразу ru, склей их с паузами, распознай GigaAM и Parakeet и проверь, что ни одна фраза не потеряна. Либо возьми мою запись с тихим собеседником, если такая есть: спроси меня.
- Проверь, что в паузах не появились выдуманные слова.

## 4. Календарь из Outlook

Настройки → Интеграции → Календарь → «Из Outlook» (код в `app/calendar_outlook.py`). Проверь вместе со мной:
- встречи на две недели видны, повторяющиеся развёрнуты, отменённых нет, участники перечислены;
- в студии видны ближайшие встречи;
- запись во время встречи получает её название и участников в «Моих заметках»;
- Outlook не просит подтверждения доступа каждый раз (один раз допустимо).

Если что-то не так, приложи текст ошибки под полем календаря и попробуй выполнить PowerShell-скрипт из `calendar_outlook.py` вручную.

## 5. Резервная копия

Настройки → Общие → Резервная копия. На копии данных, а не на настоящих, проверь:
- «Сохранить копию…» без медиа и с медиа: файл появляется, размер разумный;
- «Восстановить из копии…» на чистой папке данных: после перезапуска все записи на месте, звук играет, рядом лежит `meetings.before-restore-….db`;
- ключей облачных моделей в копии нет.

## 6. Остальное

Посмотри вместе со мной:
- «Проверено» над расшифровкой и порядок записей в «Сравнении»;
- живой перевод на встрече с русским и английским: русские фразы при переводе на русский не переводятся, а «⇄ Авто» выбирает направление по каждой фразе;
- окно «О программе» (клик по названию Verbaliox в боковой панели): анимация, клик по вербе, пять быстрых кликов.

## 7. Отчёт

Положи всё в `bench-report/check-3.md`: что работает, что нет, с текстом ошибок, плюс таблицу из пункта 2. Закоммить отчёт и `bench-report/results.json`, а исправления, если они были, — отдельными коммитами после зелёных тестов. Запушь в `claude/sweet-maxwell-uaextf`.

**Не делай:** не выпускай релиз, не меняй значения по умолчанию без моего согласия, не трогай мою настоящую папку данных и мои модели.
