# Промпт для локальной сессии: Qwen3-TTS против Chatterbox в дубляже

Скопируйте всё, что ниже линии, в новую сессию Claude Code на компьютере с VerbaScribe.

---

Ты работаешь на моём Windows-ПК с установленным VerbaScribe (локальная программа расшифровки встреч и
дубляжа). Нужно выяснить, стоит ли добавить в дубляж модель **Qwen3-TTS** (Alibaba) рядом с нынешней
**Chatterbox Multilingual** (Resemble AI, `ResembleAI/chatterbox`, MIT). Мы в программе ничего не меняем:
только проверка лицензии и замеры на реальном железе. Отвечай мне по-русски.

**Условие для модели: бесплатно и законно для коммерческого использования.** Если лицензия модели, её
токенизатора или обязательного пакета не такая (или отличается от Apache-2.0, которую называют обзоры),
остановись и спроси меня, прежде чем продолжать.

## 0. Подготовка (ничего не ломать)

1. Спроси меня, где установлен VerbaScribe (папка с `VerbaScribe.exe`, `.venv` и `.venv-dub`). Дальше это `APP`.
2. Склонируй репозиторий рядом (или обнови) и перейди на `main`:
   ```
   git clone https://github.com/pravken/VerbaScribe.git VerbaScribe-tts
   cd VerbaScribe-tts
   git checkout main
   git pull
   ```
3. **Мои данные и модели не трогаем.** Работай с копией базы и пустой папкой моделей:
   ```
   mkdir %TEMP%\vs-tts-data
   copy "%LOCALAPPDATA%\VerbaScribe\meetings.db" %TEMP%\vs-tts-data\
   set VERBASCRIBE_DATA_DIR=%TEMP%\vs-tts-data
   set VERBASCRIBE_MODELS_DIR=%TEMP%\vs-tts-models
   set VERBASCRIBE_SKIP_MIGRATION=1
   ```
   Окружение дубляжа программы (`APP\.venv-dub`) тоже не меняем.
4. Попроси меня закрыть VerbaScribe на время замеров: программа делит видеокарту (RTX 3090 24 ГБ), и
   время и память будут неверными.

## 1. Лицензии по первоисточникам

Открой и запиши точную лицензию и ограничения (дословно, со ссылкой):

- репозиторий `QwenLM/Qwen3-TTS` на GitHub (файл LICENSE);
- карточки моделей на Hugging Face: Base 0.6B и 1.7B (клонирование голоса), CustomVoice (готовые голоса),
  токенизатор речи — точные имена репозиториев посмотри в README;
- пакет на PyPI, через который модель запускается (например, `qwen-tts`), и его прямые зависимости:
  нет ли среди них GPL или пакета с некоммерческой лицензией.

Запиши, есть ли в лицензии или карточке требования к сгенерированному голосу (согласие, маркировка),
и сравни с тем, что программа уже делает (`docs/dubbing.md`, раздел «Consent and marking of generated files»).

## 2. Отдельное окружение

Qwen3-TTS почти наверняка требует других версий `transformers` и `torch`, чем Chatterbox
(`requirements-dub.in`: torch 2.6, transformers 5.2.0). Поэтому ставь его в **отдельный** venv во
временной папке, а не в `.venv-dub`:
```
py -3.10 -m venv %TEMP%\vs-qwen-tts-venv
%TEMP%\vs-qwen-tts-venv\Scripts\python -m pip install <пакет и версии из README>
```
Модели скачивай в `%TEMP%\vs-tts-models` (переменная `HF_HOME` на время сессии). Запиши точные версии
пакетов и **коммит** каждой скачанной модели на Hugging Face (`HfApi().model_info(...).sha`): если модель
войдёт в программу, она будет закреплена по коммиту, как остальные.

## 3. Материал для сравнения

1. Вместе со мной выбери 3 записи из копии базы: разные голоса (мужской, женский), одна с шумом или
   плохим микрофоном. Для каждой вырежи во временную папку 10–15 фраз одного участника по
   `segments` из базы (FFmpeg программы, `APP\...\ffmpeg.exe`, или `tools/profile_dub.py` для вырезки).
2. Образец голоса для клонирования — 5–10 секунд чистой речи этого участника, тот же для обеих моделей.
3. Тексты для озвучки: те же фразы, переведённые на английский (как в настоящем дубляже), и на русском
   (проверка русского: ударения, числа, сокращения, имена). Добавь 5 фраз с числами и датами
   («в 14:30, 3 марта 2026 года»), 3 с английскими словами внутри русского текста.

## 4. Замеры

Для каждой модели — Chatterbox Multilingual в `APP\.venv-dub` и Qwen3-TTS Base 0.6B и 1.7B в новом venv:

- **Похожесть голоса:** косинус эмбеддингов ECAPA между образцом и озвучкой. В программе это SpeechBrain ECAPA
  (`app/diarizer.py`, `_get_ecapa_encoder`), бери его, чтобы цифры были сопоставимы.
- **Разборчивость:** распознай каждую озвученную фразу GigaAM v3 (русский) или Whisper (английский) и
  посчитай WER относительно исходного текста. Отдельно — пропущенные и выдуманные слова.
- **Скорость:** отношение времени синтеза к длительности звука (RTF), первая фраза (с загрузкой модели)
  отдельно от остальных.
- **Память:** пик видеопамяти (`torch.cuda.max_memory_allocated` и `nvidia-smi` во время синтеза) и
  поместятся ли рядом модель Ollama для перевода (qwen3.5:4b) и распознавание.
- **На слух (вместе со мной):** слепое сравнение — 10 пар фраз в случайном порядке, без названий моделей; я
  выбираю лучшую или «одинаково». Отдельно отметь артефакты: обрывы, бормотание, чужой акцент, тишину.
- **Длительность:** насколько озвучка длиннее или короче оригинала (дубляжу важно попадать во время фразы).

## 5. Отчёт

Запиши в `bench-report/qwen3-tts.md`:

- лицензии с цитатами и ссылками (раздел 1) и вывод: подходит или нет;
- версии пакетов, коммиты моделей, оборудование;
- таблица по каждой модели и записи: похожесть, WER, RTF, пик видеопамяти, расхождение длительности;
- итог слепого сравнения и замеченные артефакты;
- рекомендация: заменить Chatterbox, добавить Qwen3-TTS как второй движок (какой размер), или не брать — и
  почему; что понадобится для встраивания (отдельное окружение, lock с хешами, закреплённые коммиты,
  строка в таблице лицензий README).

Закоммить отчёт в новую ветку от `main` и запушь её. В `main` не пушь, релиз не выпускай, код программы
не меняй. Временные папки (`%TEMP%\vs-tts-*`, `%TEMP%\vs-qwen-tts-venv`) в конце предложи удалить.
