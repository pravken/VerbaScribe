**VerbaScribe** — это минималистичное настольное приложение в стиле macOS (вдохновлённое *MacWhisper* и *Apple Voice Memos*) для **100% локальной и бесплатной** расшифровки видео/аудио встреч, разделения спикеров по голосам без токенов и генерации структурированных AI-протоколов.

Все вычисления выполняются **строго на вашем компьютере** (NVIDIA GPU CUDA или CPU). Никакие аудиозаписи или тексты никогда не отправляются в облако — полностью совместимо с корпоративными требованиями ИБ и NDA.

---

## ✨ Ключевые возможности (Features)

- **🚀 Локальное распознавание речи (`faster-whisper` + `Silero VAD`)**:
  - Поддержка `large-v3-turbo`, `large-v3`, `medium`, `small` с автоматическим подбором точности (`float16`, `int8_float16`, `int8`) под вашу видеокарту (от 4 ГБ до 24 ГБ VRAM) или процессор.
- **👥 Разделение спикеров по голосам БЕЗ токенов и регистраций (`SpeechBrain ECAPA-TDNN`)**:
  - Автоматическое определение количества участников встречи, кластеризация тембров голоса, прослушивание образца голоса в 1 клик и переименование участников во всём документе.
- **✨ Студийная очистка голоса и шумоподавление (`Studio Voice Denoise & Loudnorm`)**:
  - Автоматический фильтр FFmpeg (`highpass` + `lowpass` + адаптивный спектральный шумодав `afftdn` + удаление щелчков клавиш/мыши `adeclick` + динамическое выравнивание громкости тихих и громких спикеров `dynaudnorm`).
  - Живой переключатель **«✨ Чистый голос»** прямо в плеере (Web Audio API компрессор и голосовой фильтр).
- **🧹 Очистка речи от слов-паразитов (`Clean Speech`)**:
  - Автоматическое и ручное удаление голосовых хезитаций (*«э-э», «ммм», «ну типа», «как бы», «uh», «um»*) и заиканий с сохранением пословных таймкодов.
- **🧠 Локальные AI-протоколы, задачи и Q&A (`Ollama`)**:
  - Генерация подробного протокола встречи, списка задач (Action Items), краткой выжимки (TL;DR) и ответы на любые вопросы по тексту встречи через 100% открытые модели с лицензией **Apache 2.0** (`Qwen 2.5 7B / 14B / 1.5B`, `Mistral 7B`).
- **🎬 Интерактивный плеер с кликабельным текстом**:
  - Клик по любому слову перематывает видео/аудио на нужную секунду; автопрокрутка за живой речью («Следить»), скорости `1.0× – 2.0×`, склейка соседних реплик («⇈ Склеить»).
- **🎙 Встроенная запись с микрофона (`● Запись`)**:
  - Записывайте созвоны и голосовые заметки прямо внутри приложения с индикатором уровня звука и мгновенной отправкой в расшифровку.
- **🔍 Глобальный поиск по всем встречам**:
  - Мгновенный полнотекстовый поиск слова или фразы сразу по всей базе записей с переходом к нужной минуте разговора.
- **📖 Пользовательский словарь и пакетная очередь**:
  - Добавляйте фамилии коллег, названия проектов и специфические термины для безупречного распознавания.
- **📤 Экспорт в 5 форматов**:
  - `Word (.docx)`, `Markdown (.md)`, `Text (.txt)`, `Subtitles (.srt)`, `JSON (.json)`.

## 📦 Быстрый старт (Установка и запуск)

Программа распространяется **без тяжёлых нейросетей в архиве** (~85 КБ), а все нужные модели скачиваются в 1 клик через встроенный менеджер моделей при первом открытии:

1. Склонируйте репозиторий или распакуйте архив:
   ```bash
   git clone https://github.com/<your-username>/VerbaScribe.git
   cd VerbaScribe
   ```
2. Запустите **`VerbaScribe.exe`** (или `start.bat`):
   - При первом запуске на новом ПК программа автоматически создаст виртуальное окружение `.venv` и установит зависимости (`setup.bat`).
   - Откроется нативное окно приложения **VerbaScribe** с мастером первичной настройки, где можно в 1 клик скачать модель Whisper и локальную LLM с живым прогресс-баром и логами.

> **Требования**: Windows 10/11 (64-bit), установленный `FFmpeg` в `PATH` (или `winget install Gyan.FFmpeg`). Видеокарта NVIDIA (рекомендуется) или современный процессор CPU.
